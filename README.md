# Hotel-Management-System-Mid-Mountain-Hotel
A course assignment after I learning"Web Programming".
========================================
   Mid-Mountain Hotel 酒店管理系统
========================================

【项目简介】
酒店综合管理平台，包含6个业务子系统。

【技术栈】
- HTML5
- CSS3
- JavaScript

【项目结构】
- importantPages/    主页和子系统选择页
- subsystems/        6个子系统模块
- pages/             辅助页面
- css/               样式文件
- js/                JavaScript文件

【功能列表】
- 财务管理：收支记录、数据仪表盘
- 餐饮管理：菜单管理、在线点餐
- 客房管理：房间预订、状态管理
- 娱乐管理：KTV、SPA预订
- 员工管理：员工信息、排班
- 库房管理：库存跟踪

【如何运行】
用浏览器打开 importantPages/index.html
